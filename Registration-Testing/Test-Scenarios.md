# Registration – Test Scenarios

| ID | Scenario |
|---|---|
| TS-REG-001 | Verify registration with valid username and matching passwords |
| TS-REG-002 | Verify behavior when registering with an existing username |
| TS-REG-003 | Verify validation when password and confirmation do not match |
| TS-REG-004 | Verify validation when all fields are empty |
| TS-REG-005 | Verify validation when confirmation password is empty |
| TS-REG-006 | Verify username rejects uppercase letters and unsupported characters |
| TS-REG-007 | Verify username minimum length (3 characters) |
| TS-REG-008 | Verify username cannot start with a hyphen |
| TS-REG-009 | Verify username maximum length (39 characters) |
| TS-REG-010 | Verify username cannot end with a hyphen |
| TS-REG-011 | Verify username rejects spaces |

## Notes
- These scenarios cover the rules observed during this manual practice session.
- Additional cases, such as consecutive hyphens and password-strength boundaries, can be added in a later iteration.
